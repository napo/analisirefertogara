Referto Volley · Informativa sulla privacy

Chi gestisce l’app

Referto Volley è software libero sviluppato da Maurizio Napolitano. Per contatti usa l’indirizzo riportato nella pagina Informazioni dell’app.

Dati trattati

L’app tratta i dati contenuti nei referti che importi o inserisci: squadre, punteggi, formazioni, nomi di atlete, atleti e ufficiali di gara, anche minorenni, e i PDF originali. L’analisi, compreso il riconoscimento ottico dei caratteri, avviene sul dispositivo.

Dove restano

I dati restano nell’archivio locale del browser o dell’app. Il progetto non ha un server che li riceva. Lasciano il dispositivo solo per una tua scelta: quando esporti un archivio, colleghi un servizio cloud o invii un file all’autore.

Sincronizzazione con Google Drive, Dropbox o OneDrive

È facoltativa: finché non colleghi un servizio l’app non lo contatta. Collegandolo, i dati delle gare e i PDF originali sono copiati in file nel tuo spazio, direttamente dal dispositivo. L’accesso è limitato ai file creati dall’app (Google Drive) o alla sua cartella (Dropbox, OneDrive). I token di accesso restano sul dispositivo e non sono condivisi con nessuno. Al file si applicano le condizioni del servizio che hai scelto.

Scollegando il servizio i token vengono cancellati e, dove il servizio lo consente, l’accesso viene revocato; i dati restano sul dispositivo e, se lo chiedi, i file vengono spostati nel cestino. L’uso dei dati ricevuti dalle API di Google rispetta le Google API Services User Data Policy, compresi i requisiti di uso limitato: l’app li usa solo per la sincronizzazione.

File inviati all’autore

Chi segnala un errore può inviare volontariamente un referto via email. Il file è conservato sul computer dell’autore, usato solo per migliorare il progetto, non è pubblicato né condiviso con altri ed è cancellato quando non serve più o su richiesta. Nei test pubblici del progetto finiscono solo letture anonimizzate: senza nomi, luogo, numero gara e data, ma con i numeri di maglia e i punteggi originali.

Altri collegamenti

L’app controlla la disponibilità di aggiornamenti su GitHub. I collegamenti esterni, come PayPal, si aprono solo se li scegli.
