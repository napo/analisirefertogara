# Font locali

Font variabili originali da google/fonts, scaricati il 25 settembre 2026:

- Montserrat: https://github.com/google/fonts/tree/main/ofl/montserrat
- Roboto: https://github.com/google/fonts/tree/main/ofl/roboto
- Rubik: https://github.com/google/fonts/tree/main/ofl/rubik

I file TTF includono tutti i pesi utilizzati dall’interfaccia e sono serviti localmente da `fonts.css`. Ogni font conserva la propria licenza SIL Open Font License nel file `*-OFL.txt`. Nessuna richiesta a Google Fonts viene effettuata durante l’uso dell’applicazione.

Caratteri per l’accessibilità (pannello “Accessibilità”), scaricati il 28 novembre 2026 dai pacchetti Fontsource, sottoinsieme latino (comprende le lettere accentate italiane):

- Atkinson Hyperlegible Next (carattere ad alta leggibilità del Braille Institute), variabile 200–800, normale e corsivo: https://github.com/googlefonts/atkinson-hyperlegible-next
- OpenDyslexic (pensato per chi ha dislessia), pesi 400 e 700 e corsivo 400: https://github.com/antijingoist/opendyslexic

Licenza SIL Open Font License in `atkinson-hyperlegible-next-OFL.txt` e `opendyslexic-OFL.txt`. Il browser li scarica solo quando vengono scelti.
