# Font locali

Font variabili originali da google/fonts, scaricati il 25 settembre 2026:

- Montserrat: https://github.com/google/fonts/tree/main/ofl/montserrat
- Roboto: https://github.com/google/fonts/tree/main/ofl/roboto
- Rubik: https://github.com/google/fonts/tree/main/ofl/rubik

I file TTF includono tutti i pesi utilizzati dall’interfaccia e sono serviti localmente da `fonts.css`. Ogni font conserva la propria licenza SIL Open Font License nel file `*-OFL.txt`. Nessuna richiesta a Google Fonts viene effettuata durante l’uso dell’applicazione.
